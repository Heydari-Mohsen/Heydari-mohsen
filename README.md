## ✦ A Thought

<p align="center">
  ɪɴ ᴀ ᴡᴏʀʟᴅ ᴡʜᴇʀᴇ ᴇᴠᴇʀʏᴛʜɪɴɢ ꜱᴇᴇᴍꜱ ᴛᴏ ʙᴇ ᴘʀᴇᴅᴇꜰɪɴᴇᴅ,<br>
  ɪ Qᴜɪᴇᴛʟʏ ꜰɪɴᴅ ᴍʏ ᴡᴀʏ ꜱᴏᴍᴇᴡʜᴇʀᴇ ʙᴇᴛᴡᴇᴇɴ ᴄʀᴇᴀᴛɪɴɢ ᴀɴᴅ ᴜɴᴅᴇʀꜱᴛᴀɴᴅɪɴɢ.<br><br>

  ᴛʜᴇʀᴇ ɪꜱ ꜱᴛɪʟʟ ꜱᴏᴍᴇᴛʜɪɴɢ ʙᴇᴀᴜᴛɪꜰᴜʟ ᴀʙᴏᴜᴛ ʙʀɪɴɢɪɴɢ ɪɴᴛᴏ ᴇxɪꜱᴛᴇɴᴄᴇ ᴡʜᴀᴛ ᴏɴᴄᴇ ᴅɪᴅ ɴᴏᴛ ᴇxɪꜱᴛ.<br><br>

  ᴀɴ ɪᴅᴇᴀ, ᴀ ꜰᴇᴡ ʟɪɴᴇꜱ ᴏꜰ ᴄᴏᴅᴇ, ᴀɴᴅ ᴀ ʟɪᴛᴛʟᴇ ᴄᴏᴜʀᴀɢᴇ;<br>
  ᴀɴᴅ ꜱʟᴏᴡʟʏ, ꜱᴏᴍᴇᴛʜɪɴɢ ᴛᴀᴋᴇꜱ ꜱʜᴀᴘᴇ ᴛʜᴀᴛ ᴡᴀꜱ ᴏɴʟʏ ᴀ ᴛʜᴏᴜɢʜᴛ ʏᴇꜱᴛᴇʀᴅᴀʏ.<br><br>

  ᴘᴇʀʜᴀᴘꜱ ʟɪꜰᴇ ɪꜱ ᴍᴜᴄʜ ᴛʜᴇ ꜱᴀᴍᴇ; ᴘᴇʀʜᴀᴘꜱ ᴏɴᴇ ᴅᴀʏ,<br>
  ᴡʜᴀᴛ ɪꜱ ᴏɴʟʏ ᴀ ʟɪɴᴇ ᴏꜰ ᴄᴏᴅᴇ ᴛᴏᴅᴀʏ ᴡɪʟʟ ʙᴇᴄᴏᴍᴇ ᴘᴀʀᴛ ᴏꜰ ᴀ ᴅʀᴇᴀᴍ<br>
  ᴛʜᴀᴛ ʜᴀꜱ ʟɪᴠᴇᴅ ɪɴ ᴍʏ ᴍɪɴᴅ ꜰᴏʀ ʏᴇᴀʀꜱ.
</p>
